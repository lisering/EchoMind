# 需求→测试可追溯性矩阵（Requirements Traceability Matrix）

> **目的**：消除根因 V1（实现驱动测试），确保每个 SRS 需求从用户视角被验证。

## 使用方法

- 每个 REQ-XXX 必须关联至少一个测试用例
- 测试用例必须从**用户视角**验证需求（而非验证实现细节）
- 状态列：✅ 覆盖 | ⚠️ 部分覆盖 | ❌ 未覆盖
