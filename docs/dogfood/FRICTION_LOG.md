## 已知摩擦基线（来自历史审计，dogfooding 中重点观察验证）

以下条目来自 S1-S4 UX 审计与 V3.1 调研，dogfooding 时优先留意是否仍然存在：

1. [ ] 长会话（100+ 条消息）打开耗时（P4-5 渐进渲染已做首屏优化，验证体感）
2. [ ] 批量导入时进度条与文档列表的刷新体验（P2-2 合流后是否仍有闪动）
3. [ ] 流式长代码回答的渲染流畅度（P4-1/P2-1 限频豁免后的体感帧率）
4. [ ] 设置面板 8 分区信息架构是否符合自己的心智模型
5. [ ] 斜杠命令 /web /agent 的临时开关行为是否可感知、可理解
6. [ ] 三语言切换后的完整性（抽查 ja/en 界面有无中文漏网）
7. [ ] 锁屏 → 解锁流程的打断感
8. [ ] 应用冷启动到可交互的真实时长
