### 1.2 评估维度说明

- **用户价值 (40%)**：功能对用户的直接帮助程度（律师/研究者日常使用场景）
- **实现易度 (30%)**：代码复杂度、新增依赖、改动范围（越高越容易）
- **架构收益 (20%)**：对代码架构的改善、可复用性、技术债减少
- **风险控制 (10%)**：引入 bug 的风险、数据安全、向后兼容性

### 1.3 入选标准

ROI ≥ 5.5 且单 Session 可完成。最终入选 3 项功能，分 4 个 Session 实施（S1-S3 功能 + S4 发布）。

## 2. 选定功能

### 2.1 S1: 文档内容预览（REQ-ING-010）

**目标**：点击文档列表中的文档名弹出预览面板，显示文档元数据（文件名、格式、大小、导入时间、chunk 数、索引状态）与原文前 500 字预览。Indexed 文档额外显示 chunk 列表。

**后端**：
- 新增 `get_document_preview` IPC 命令：返回文档元数据 + 前 500 字内容 + chunk 列表（sequence + content 前 200 字）
- 复用已有 `Storage::list_chunks(doc_id)` 获取 chunk 列表
- 复用已有 `Storage::get_document(id)` 获取文档元数据

**前端**：
- 新增 `ui/src/doc-preview.js` 模块：预览面板渲染 + Focus Trap + ESC 关闭
- `ui/src/main.js`：文档列表项点击触发预览
- `ui/index.html`：预览面板容器
- `ui/locales/{en,zh-CN}.json`：i18n 键

**改动文件**：
| 文件 | 改动 |
|---|---|
| `crates/models/src/lib.rs` | 新增 `DocumentPreview` 结构体 |

| `crates/infra/src/sqlite_storage.rs` | 实现 `get_document_preview` |
| `crates/tauri-app/src/commands/document.rs` | 新增 `get_document_preview` IPC |
| `crates/tauri-app/src/lib.rs` | 注册新命令 |

### 2.2 S2: 加载状态与骨架屏（REQ-IX-007）
