### 1.2 评估维度说明

- **用户价值 (40%)**：功能对用户的直接帮助程度（律师/研究者日常使用场景）
- **实现易度 (30%)**：代码复杂度、新增依赖、改动范围（越高越容易）
- **架构收益 (20%)**：对代码架构的改善、可复用性、技术债减少
- **风险控制 (10%)**：引入 bug 的风险、数据安全、向后兼容性

## 2. 选定功能

### 2.1 S1: 右键上下文菜单增强（REQ-IX-001）

**目标**：在文档列表、会话列表、聊天区域等核心 UI 元素上实现标准化右键上下文菜单，提供常用操作快捷入口。

**实现内容**：
- `ui/src/context-menu.js`：增强现有基础，添加菜单项分组、快捷键提示、边界检测、灰显逻辑
- 文档列表右键：删除、预览、重新索引、在文件夹中显示
- 会话列表右键：删除、导出、重命名、新建分支
- 聊天区域右键：复制、朗读、删除消息、查找相关文档
- 菜单项根据上下文状态动态灰显（如无权限、加载中）

**改动文件**：
