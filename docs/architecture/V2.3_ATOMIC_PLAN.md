## 3. 功能详情

### 3.1 S81: 文件夹拖拽导入 + P2-7 智能模式 RAG 参数调优

#### REQ-ING-023 文件夹拖拽导入
- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：REQ-ING-001
- **描述**：用户可拖拽文件夹到主窗口，自动遍历子目录中所有支持格式的文件批量导入。递归遍历深度上限 5 层，跳过隐藏文件/目录（`.git` / `node_modules` / `.DS_Store` 等）。拖拽文件夹时显示文件数量预览。
- **验收标准**：
  - AC-1：拖拽文件夹到主窗口，自动遍历并导入所有支持格式的文件（TC-ING-FOLDER-001）
  - AC-2：递归遍历深度上限 5 层，超出部分跳过并日志记录（TC-ING-FOLDER-002）
  - AC-3：跳过隐藏文件和目录（`.git` / `node_modules` / `.DS_Store` / `__pycache__`）（TC-ING-FOLDER-003）
  - AC-4：拖拽文件夹时显示文件数量预览「找到 N 个可导入文件」（TC-ING-FOLDER-004）
  - AC-5：导入过程中显示进度（已导入 X / 共 Y 个文件）（TC-ING-FOLDER-005）
- **契约**：`ui/src/import.js` dragenter/drop 事件检测 DataTransferItem.isDirectory → 递归遍历 → `import_files` IPC 批量导入 + 进度事件
- **关键文件**：`ui/src/import.js`、`crates/tauri-app/src/commands/import.rs`

#### REQ-RAG-050 智能模式 RAG 参数调优（P2-7）
- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：无
- **描述**：智能模式开启时，默认 RAG 参数从保守值调整为优化值：top_k 从 5 调整到 8（扩大候选池）、score 阈值从 0.1 降到 0.05（降低过滤门槛）、Chunk Expansion 从 1 扩展到 2（增加上下文窗口）。智能模式关闭时恢复保守值。
- **验收标准**：
  - AC-1：智能模式开启时 top_k 默认值 = 8（TC-RAG-SMART-001）
  - AC-2：智能模式开启时 score 阈值 = 0.05（TC-RAG-SMART-002）
  - AC-3：智能模式开启时 Chunk Expansion 窗口 = 2（TC-RAG-SMART-003）
  - AC-4：智能模式关闭时恢复保守值（top_k=5, threshold=0.1, expansion=1）（TC-RAG-SMART-004）
  - AC-5：参数变更持久化到 settings 表（TC-RAG-SMART-005）
- **契约**：`crates/tauri-app/src/commands/chat.rs` 读取 smart_mode 设置时覆盖默认参数 + `crates/tauri-app/src/state.rs` smart_mode 字段
- **关键文件**：`crates/tauri-app/src/commands/chat.rs`、`crates/tauri-app/src/state.rs`

### 3.2 S82: 嵌入模型下载境内加速（P2-8）

#### REQ-VEC-017 嵌入模型下载境内加速
- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：REQ-VEC-003
- **描述**：fastembed 默认从 HuggingFace 下载 ONNX 模型，境内 GFW 导致超时。当前已有 3 源容错（ModelScope → hf-mirror → HuggingFace），但缺少：(1) 下载重试机制（3 次重试 + 退避）；(2) 断点续传（HTTP Range 请求）；(3) 用户可配置镜像源。
- **验收标准**：
  - AC-1：模型下载失败时自动重试 3 次，退避间隔 2s/4s/8s（TC-VEC-ACCEL-001）
  - AC-2：支持断点续传（HTTP Range 请求，已下载部分不重复）（TC-VEC-ACCEL-002）
  - AC-3：用户可在设置中手动选择镜像源（auto/ModelScope/hf-mirror/HuggingFace）（TC-VEC-ACCEL-003）
  - AC-4：下载进度事件包含当前源 URL（TC-VEC-ACCEL-004）
  - AC-5：所有源均失败时显示友好错误信息 + 手动重试按钮（TC-VEC-ACCEL-005）
- **契约**：`crates/infra/src/local_embedder.rs` 下载逻辑增强 + `ui/src/settings.js` 镜像源选择器
- **关键文件**：`crates/infra/src/local_embedder.rs`、`ui/src/settings.js`
- **注意**：铁律一 — 下载使用 `.no_proxy()` 直连（开发调研时可设代理）

### 3.3 S83: 无 Key 演示模式

#### REQ-RAG-051 无 Key 演示模式
- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：REQ-RAG-001
- **描述**：首次使用时向导 Step 2 提供「跳过配置，使用示例知识库体验」选项。用户无需 API Key 即可体验基础 RAG 功能：内置 3 个示例文档（EchoMind 介绍 / RAG 技术概述 / 隐私安全说明）+ 使用 mock LLM 返回预设回答（基于关键词匹配的模板回复）。用户配置 API Key 后自动退出演示模式。
- **验收标准**：
  - AC-1：向导 Step 2 显示「跳过，使用演示模式」按钮（TC-RAG-DEMO-001）
  - AC-2：演示模式下自动导入 3 个示例文档（TC-RAG-DEMO-002）
  - AC-3：演示模式下对话返回预设回答（基于关键词匹配模板）（TC-RAG-DEMO-003）
  - AC-4：演示模式下顶部显示「演示模式 — 配置 API Key 以解锁完整功能」提示栏（TC-RAG-DEMO-004）
  - AC-5：用户配置 API Key 后自动退出演示模式，清除示例文档（TC-RAG-DEMO-005）
- **契约**：`ui/src/main.js` 向导新增演示模式分支 + `ui/src/chat.js` 演示模式 mock LLM 回复 + `crates/tauri-app/src/commands/chat.rs` 演示模式检测
- **关键文件**：`ui/src/main.js`、`ui/src/chat.js`、`crates/tauri-app/src/commands/chat.rs`

### 3.4 S84: Agent 步骤可视化增强

#### REQ-RAG-052 Agent 步骤可视化增强
- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：REQ-RAG-022
- **描述**：当前 Agent ReAct 步骤事件（agent_step）前端展示简陋。增强为：Thought / Action / Observation 三步分卡片展示，每个卡片含步骤编号 + 图标 + 折叠/展开 + 耗时标注。支持多 Action 并行展示。最大 5 轮迭代用进度条标注（第 N/5 轮）。
- **验收标准**：
  - AC-1：Agent 模式下每步生成独立卡片（Thought/Action/Observation 分卡片）（TC-RAG-AGENT-VIS-001）
  - AC-2：每个卡片显示步骤编号 + 类型图标 + 耗时（TC-RAG-AGENT-VIS-002）
  - AC-3：卡片默认折叠，点击展开查看详情（TC-RAG-AGENT-VIS-003）
  - AC-4：多 Action 并行执行时同列展示多个 Action 卡片（TC-RAG-AGENT-VIS-004）
  - AC-5：底部进度条显示「第 N/5 轮推理」（TC-RAG-AGENT-VIS-005）
  - AC-6：最终回答正常流式输出，Agent 步骤卡片在回答之前（TC-RAG-AGENT-VIS-006）
- **契约**：`ui/src/thinking-panel.js` 扩展为 Agent 步骤可视化容器 + `ui/src/chat.js` agent_step 事件处理
- **关键文件**：`ui/src/thinking-panel.js`、`ui/src/chat.js`、`ui/styles/components.css`
