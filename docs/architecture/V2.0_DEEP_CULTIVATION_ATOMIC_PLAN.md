### 4.1 Session S07: CI 基础流水线

**创建 `.github/workflows/ci.yml`**:

```yaml
name: CI
on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  rust-checks:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        features: ['', '--features pro']
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: Install system deps (ONNX/Tauri)
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
      - name: Clippy
        run: cargo clippy --all-targets ${{ matrix.features }} -- -D warnings
      - name: fmt
        run: cargo fmt --check
      - name: Test
        run: cargo test ${{ matrix.features }}

  frontend-checks:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Build UI
        run: node scripts/build-ui.mjs
      - name: TypeScript check
        run: npx tsc --noEmit
      - name: Vitest
        run: cd e2e-tests && npm install && npm run test:unit

  e2e-bridge:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Build UI
        run: node scripts/build-ui.mjs
      - name: E2E Bridge Tests
        run: cd e2e-tests && npm install && npx playwright install --with-deps chromium && npm run test:bridge
```

### 4.2 Session S08: CI 增强 — 跨平台安装包构建 + 前端检查 + CI 优化（✅ 2026-08-15）

**实际实现内容**（超越原始计划）:

S08 在 S07 基础流水线上增强了 3 项能力：

1. **新增 `frontend-checks` job** — tsc 类型检查 + esbuild 打包 + Vitest 单元测试（独立并行，与 `lint` + `supply-chain` 同时运行）
2. **新增 `release-build` job** — `cargo tauri build --features pro` 产出跨平台安装包（.dmg/.msi/.exe/.deb/.AppImage），仅 push to main 触发
3. **CI 优化** — `test` 依赖 `lint` + `frontend-checks` 双门控；`e2e-bridge` 依赖 `test` + `frontend-checks`；npm cache 加速；`workflow_dispatch` 手动触发

**最终 8 job + 1 report job 结构**:

| # | Job | 触发 | 依赖 | 说明 |
|---|---|---|---|---|
| 1 | `lint` | all | — | fmt + clippy (Free+Pro) |
| 2 | `frontend-checks` | all | — | tsc + esbuild + Vitest |
| 3 | `supply-chain` | all | — | cargo-audit + cargo-deny |
| 4 | `test` | all | lint + frontend-checks | cargo test (Free+Pro) + chaos |
| 5 | `build-matrix` | all | test | 4 OS release build (Free+Pro) |
| 6 | `release-build` | push to main | build-matrix | `cargo tauri build` → 安装包 artifact |
| 7 | `e2e-bridge` | all | test + frontend-checks | Playwright 4 shard (ubuntu+macos) |
| 8 | `e2e-bridge-report` | all | e2e-bridge | 合并 HTML 报告 |
| 9 | `e2e-gui` | all | build-matrix | WebdriverIO (ubuntu+windows) |

**release-build 产出**:

| 平台 | 安装包 |
|---|---|
| macOS-arm64 | `.dmg` |
| macOS-x64 | `.dmg` |
| Windows-x64 | `.msi` + `.exe` (NSIS) |
| Linux-x64 | `.deb` + `.AppImage` |
