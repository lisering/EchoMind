### 1.2 评估维度说明

- **用户价值 (40%)**：功能对用户的直接帮助程度（律师/研究者日常使用场景）
- **实现易度 (30%)**：代码复杂度、新增依赖、改动范围（越高越容易）
- **架构收益 (20%)**：对代码架构的改善、可复用性、技术债减少
- **风险控制 (10%)**：引入 bug 的风险、数据安全、向后兼容性

## 2. 选定功能

### 2.1 S1: 前端 RAG/LLM 参数设置面板（REQ-RAG-014 + REQ-RAG-015）

**背景**：v1.9 已完成后端 IPC（`get_rag_params`/`set_rag_params`/`get_generation_params`/`set_generation_params`），但前端设置面板缺少对应的 UI 控件。

**目标**：在设置面板中新增 RAG 检索参数区和 LLM 生成参数区，用户可通过滑块/输入框调整参数，保存后对新查询生效。

**UI 设计**：
- RAG 参数区：top_k 滑块（1-20）、相似度阈值滑块（0.0-1.0）、Chunk Expansion 开关、扩展窗口滑块（0-3）
- LLM 参数区：temperature 滑块（0.0-2.0）、max_tokens 输入框（256-8192）、top_p 滑块（0.0-1.0）
- 每个控件旁显示当前值
- 保存按钮统一持久化到 settings 表

**改动文件**：
| 文件 | 改动 |
|---|---|
| `ui/src/settings.js` | 新增 `renderRagParams()` + `renderLlmParams()` 渲染函数 |
| `ui/src/ipc.js` | 新增 `ragParamsApi` + `generationParamsApi` IPC 封装 |
| `ui/index.html` | 设置面板新增 RAG/LLM 参数区 HTML |
| `ui/locales/{en,zh-CN}.json` | 新增 i18n 键 |
| `e2e-tests/tests/bridge/tauri-stub.js` | 新增 4 个 IPC mock |

**E2E 测试计划**（3 个测试）：
| TC ID | 描述 |
|---|---|
| TC-V10-RAG-001 | 设置面板显示 RAG 参数区（top_k 滑块 + 阈值滑块 + 扩展开关） |
| TC-V10-LLM-001 | 设置面板显示 LLM 参数区（temperature 滑块 + max_tokens 输入 + top_p 滑块） |
| TC-V10-PARAMS-SAVE-001 | 修改参数后保存，重新打开设置面板恢复保存的值 |

### 2.2 S2: 文档列表排序下拉（REQ-ING-008）

**背景**：v1.9 已完成后端 `get_documents(sort_by, sort_order)` IPC + `sort_documents()` 纯函数，但前端 `docApi.list()` 调用时未传递排序参数，且无排序 UI。

**目标**：知识库面板头部新增排序下拉菜单，用户可选择按导入时间/文件名/文件大小排序，支持升序/降序切换。排序选择在当前会话内保持。

**UI 设计**：
- KB 面板标题栏右侧新增排序按钮（图标 + 下拉箭头）
- 点击展开下拉菜单：导入时间（新→旧）、导入时间（旧→新）、文件名（A-Z）、文件名（Z-A）、文件大小（大→小）、文件大小（小→大）
- 选中项标记 ✓
- 排序选择存入 `state.js`（会话内持久）

**改动文件**：
| 文件 | 改动 |
|---|---|
| `ui/src/ipc.js` | `docApi.list` 支持 `sortBy`/`sortOrder` 参数 |
| `ui/src/main.js` | `loadDocuments()` 传递排序参数 + 排序状态管理 |
| `ui/index.html` | KB 面板头部新增排序按钮 HTML |
| `ui/locales/{en,zh-CN}.json` | 新增 i18n 键 |
| `e2e-tests/tests/bridge/tauri-stub.js` | `get_documents` mock 支持 sort_by/sort_order |

**E2E 测试计划**（2 个测试）：
| TC ID | 描述 |
|---|---|
| TC-V10-SORT-001 | 排序下拉显示 6 个选项，默认选中「导入时间（新→旧）」 |
| TC-V10-SORT-002 | 选择「文件名（A-Z）」后文档列表按字母序排列 |
