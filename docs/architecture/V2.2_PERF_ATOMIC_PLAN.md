## 二、规格定义（REQ + AC + TC）

### REQ-PERF-015 HNSW 索引持久化与懒加载（P0）

- **AC-1**：索引构建后落盘（二进制格式），文件位于数据目录 `hnsw_index.bin`。
- **AC-2**：`SqliteStorage::new()/new_encrypted()` 启动时不加载索引（懒）；首次检索时若磁盘索引存在且版本/维度匹配则加载（O(n) 图重建，无 DB 全量读取）。
- **AC-3**：磁盘索引缺失/损坏/维度不匹配 → 回退全量构建（现有路径），构建完成后自动落盘。
- **AC-4**：写入/删除 embedding 后 `mark_hnsw_dirty()` 不变；下次检索重建并覆盖落盘。
- **AC-5**：落盘文件带魔数 + 版本号 + 向量维度校验，损坏文件被安全忽略。
- **AC-6**：`HnswIndex` 新持久化格式不改变搜索语义（召回率 ≥ 90% 不变）。
- **TC**：TC-PERSIST-001~008（save/load 往返 / 魔数校验 / 维度不匹配回退 / 损坏文件回退 / dirty 重建 / 空索引 / 大索引性能护栏 / 与全量扫描一致性）

### REQ-PERF-016 向量缓存正确性修复 + 内存路径加速（P0）

- **AC-1**：修复 LRU 截断 bug：缓存容量按「内存预算」动态计算（`max_vectors = max(5000, 知识库向量总数)`），保证所有向量参与检索。
- **AC-2**：全量扫描路径 top-k 使用 BinaryHeap（O(n log k)），替代全排序 O(n log n)。
- **AC-3**：缓存命中路径零全量克隆：读锁内直接计算（Arc<RwLock> 快照语义），消除每次查询的 Vec<(String, Vec<f32>)> 深拷贝。
- **AC-4**：`set_max_vectors()` 参数化并通过设置键 `vec.max_cached_vectors` 可配置（默认 0 = 自动预算）。
- **AC-5**：>5000 向量的知识库，检索结果与全量扫描语义一致（修复后 chunk 不再静默缺失）。
- **TC**：TC-VEC-CACHE-001~006（LRU 容量自动扩展 / 超预算检索完整性 / BinaryHeap 排序正确性 / 缓存命中零克隆（引用计数验证）/ set_max_vectors 生效 / >5000 向量完整检索）

### REQ-PERF-017 余弦相似度归一化预计算（P0/P1）

- **AC-1**：`cosine_similarity` 改为 `dot_product_normalized`：向量在入库内存缓存时归一化一次，检索时仅计算点积（3 次乘加/dim → 1 次乘加/dim，~3× FLOPs 降低）。
- **AC-2**：原始 DB 存储格式不变（归一化仅作用于内存缓存副本），向后兼容。
- **AC-3**：零向量防御：归一化后全零向量得分 0.0。
- **AC-4**：HNSW 路径不受影响（hnsw_rs 内部 DistCosine 自带归一化）。
- **TC**：TC-COS-001~004（归一化点积与余弦等价 / 零向量 / 非单位向量查询等价性 / 基准护栏 10k×384 ≤ 20ms）

### REQ-PERF-018 检索管线并行化（P1）

- **AC-1**：图扩展（GraphRetriever.expand）与标准检索并行执行（`tokio::join!`），合并逻辑不变（分数取 max，截断 top_k×2）。
- **AC-2**：图扩展失败降级语义不变。
- **AC-3**：并行与串行结果一致（确定性：同分数同排序）。
- **TC**：TC-PARALLEL-001~003（并行结果等于串行结果 / 图扩展失败降级 / 空结果不崩溃）

### REQ-PERF-019 Contextual BM25（P1）

- **AC-1**：`add_chunk` 时 FTS5 索引内容使用 `build_contextual_text(doc_name, chunk_content)`（与向量嵌入同源）。
- **AC-2**：现有 `rebuild_bm25_index` IPC 同步改为使用上下文前缀文本（新库自动生效，旧库需重建，提供迁移提示）。
- **AC-3**：keyword_search 查询语义不变（仅索引内容变化）。
- **TC**：TC-CTX-BM25-001~004（FTS5 存储上下文文本 / 上下文前缀命中检索 / 重建索引包含前缀 / 无文档名时不破坏）

### REQ-PERF-020 语义缓存阈值动态校准（P2）

- **AC-1**：`SqliteCache` 增加命中率统计（hit/miss 计数 + 阈值历史）。
- **AC-2**：阈值在 [0.85, 0.97] 区间内按命中质量自适应：误命中（用户反馈无来源引用）上调阈值，零命中下调。
- **AC-3**：默认行为不变（0.92 起始值），统计清零不影响缓存内容。
- **TC**：TC-CALIB-001~003（初始阈值 / 命中率统计累加 / 阈值钳位区间）

### REQ-NFR-022 启动与首次检索延迟（P0 配套）

- **AC-1**：应用启动不触发 HNSW 构建/加载（懒加载）。
- **AC-2**：10k chunks 知识库二次启动后首次检索（索引加载路径）≤ 全量构建路径的 50%。
- **AC-3**：不引入新的启动阻塞点。
- **TC**：TC-BOOT-001~002（启动无 HNSW 构建 / 二次启动首次检索延迟护栏）
