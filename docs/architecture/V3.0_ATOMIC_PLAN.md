## 1. 背景

v2.4.0 发布后，SRS Draft REQ 再次归零。v2.0~v2.4 共 5 个版本、20+ Session 的深耕工作已完成：
- 极致性能优化 12 REQ（PERF-001~012）
- QM 借鉴 11 项（Q01-Q11）
- OpenCode 借鉴 14 项（B01-B14）
- OpenMontage 借鉴 5 项
- DS4 借鉴 3 项（DS-01~03）
- UI/UX QA 265 测试全过
- 供应链安全（h2 漏洞修复 + cargo deny 全通过）
- 前端模块精简 77→72

v3.0 是**架构升级版本**，聚焦三个方向：
1. **架构级突破**：MCP 协议支持（P0-6 插件系统），打开生态扩展能力
2. **用户体验根本改善**：设置面板重构（35→8 分区 + 智能模式 + 术语通俗化）
3. **技术债清理**：前端模块进一步精简（72→≤60）+ 开发者工具隔离

### 版本主题：**架构与生态**

v2.x 系列已将 RAG 核心能力（检索/嵌入/对话/安全/性能/多模态/本地 LLM）打磨到生产级。v3.0 转向**生态扩展**和**用户体验根本性改善**，为 v4.0 多端协同/云同步奠定架构基础。

### 3.3 S96: 嵌入模型对比评估面板

- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：REQ-VEC-003、REQ-RAG-048
- **描述**：用户可选择 2-3 个嵌入模型，对同一文档集进行嵌入并对比检索质量（Hit Rate / MRR / NDCG）。评估结果以表格 + 柱状图展示。复用已有的 RAG 评估数据集（REQ-RAG-048 `RagEvalDataset`）和评估指标（`RagEvaluator`）。帮助用户根据自身数据选择最佳嵌入模型。
- **验收标准**：

  - AC-4：柱状图可视化对比结果（TC-VEC-EVAL-004）
  - AC-5：评估过程中显示进度（逐模型嵌入 + 检索）（TC-VEC-EVAL-005）
- **契约**：`ui/src/embed-eval.js`（新建前端面板）+ `crates/tauri-app/src/commands/performance.rs`（`run_embed_comparison` IPC）+ `crates/core/src/rag_eval.rs`（复用 `RagEvaluator`）+ `crates/infra/src/local_embedder.rs`（多模型切换）
- **关键文件**：`ui/src/embed-eval.js`、`crates/tauri-app/src/commands/performance.rs`、`crates/core/src/rag_eval.rs`、`crates/infra/src/local_embedder.rs`

### 3.4 S97: MCP 协议支持 Phase 1（P0-6 插件系统） ✅

#### REQ-ARCH-016 MCP 协议适配器
- **优先级**：P0 ｜ **状态**：Implemented ｜ **依赖**：REQ-ARCH-008
- **描述**：实现 Model Context Protocol (MCP) 客户端支持，允许 EchoMind 连接外部 MCP 服务器（如文件系统、数据库、Web 搜索等工具服务器）。Phase 1 聚焦：① MCP 客户端 JSON-RPC 通信（stdio + SSE 两种 transport）② 工具注册表（MCP 工具自动注册为 Agent 可用工具）③ 安全沙箱（MCP 工具调用需用户确认）。MCP 服务器配置存储在 settings 表，支持多服务器。
- **验收标准**：
  - AC-1：设置面板新增「MCP 服务器」配置入口，支持添加/删除/启用/禁用 MCP 服务器（TC-MCP-001）
  - AC-2：支持 stdio transport（启动子进程 JSON-RPC 通信）（TC-MCP-002）
  - AC-3：支持 SSE transport（HTTP + Server-Sent Events JSON-RPC 通信）（TC-MCP-003）
  - AC-4：MCP 服务器工具自动注册到 Agent 工具列表（TC-MCP-004）
  - AC-5：MCP 工具调用前弹出确认对话框，用户可允许/拒绝（TC-MCP-005）
  - AC-6：MCP 服务器连接状态实时显示（connected/disconnected/error）（TC-MCP-006）
- **契约**：`crates/core/src/mcp/`（新建模块：`client.rs` JSON-RPC 客户端 + `transport.rs` stdio/SSE 传输层 + `registry.rs` 工具注册表 + `config.rs` 服务器配置）+ `crates/tauri-app/src/commands/mcp.rs`（6 IPC 命令）+ `ui/src/mcp-settings.js`（MCP 配置面板）
- **关键文件**：`crates/core/src/mcp/client.rs`、`crates/core/src/mcp/transport.rs`、`crates/core/src/mcp/registry.rs`、`crates/tauri-app/src/commands/mcp.rs`、`ui/src/mcp-settings.js`
- **新增依赖**：`tokio` process + io（已有）+ `serde_json`（已有）。**零新增 crate 依赖**——MCP JSON-RPC 协议用已有 tokio + serde_json 实现。
- **TDD 测试**：TC-MCP-001~006（6 单元 + 2 集成测试）
- **调研依据**：MCP 官方规范 https://spec.modelcontextprotocol.io/ + Claude Desktop MCP 实现 + Rust 生态 `rmcp` crate 评估
