## 1. 背景

v2.3.0 已发布（S81-S85 全部 Implemented）。SRS Draft 再次归零，1555 Free / 1831 Pro 测试通过。本版本聚焦**用户体验提升 + 桌面应用成熟度**，选择高 ROI 的短周期功能。

### 版本主题：**效率与可信**

用户已拥有完整的 RAG 知识库功能链路（导入→检索→对话→导出）。v2.4 聚焦三个方向：
1. **效率增强**：对话书签、批量操作、全局搜索增强
2. **桌面成熟度**：自动更新检查、macOS 代码签名与公证
3. **可扩展性**：MCP 协议支持（架构级）

## 3. 功能详情

### 3.1 S86: 对话书签/收藏 ✅

#### REQ-RAG-053 消息级书签
- **优先级**：P2 ｜ **状态**：Implemented ｜ **依赖**：REQ-RAG-006 ｜ **实现日期**：2026-08-21
- **描述**：用户可在对话中为任意 AI 回答消息添加书签（收藏），书签列表在侧栏底部显示。点击书签快速跳转到对应消息位置。书签存储在 SQLite 表中，跨会话持久化。每个书签包含：消息内容摘要（前 50 字）、会话 ID、消息 ID、创建时间、可选标签备注。
- **验收标准**：
  - AC-1：AI 消息操作栏新增「书签」按钮，点击后添加书签（TC-RAG-BMK-001）
  - AC-2：侧栏底部书签列表显示已收藏消息摘要 + 会话名（TC-RAG-BMK-002）
  - AC-3：点击书签跳转到对应会话 + 消息位置并高亮（TC-RAG-BMK-003）
  - AC-4：书签可添加备注标签（≤ 50 字）（TC-RAG-BMK-004）
  - AC-5：书签可删除，删除后侧栏列表实时更新（TC-RAG-BMK-005）
- **契约**：`crates/models/src/lib.rs`（`Bookmark` 结构体）+ `crates/infra/src/sqlite_storage.rs`（`bookmarks` 表 + 4 方法）+ `crates/tauri-app/src/commands/conversation.rs`（4 IPC：add_bookmark/list_bookmarks/delete_bookmark/get_bookmark_by_message）+ `ui/src/bookmarks.js`（侧栏书签列表 UI）
- **关键文件**：`crates/models/src/lib.rs`、`crates/infra/src/sqlite_storage.rs`、`crates/tauri-app/src/commands/conversation.rs`、`ui/src/bookmarks.js`、`ui/src/chat-render.js`

### 3.2 S87: 自动更新检查

#### REQ-HELP-004 自动更新检查（前端增强）
- **优先级**：P2 ｜ **状态**：Implemented ｜ **依赖**：REQ-SEC-003
- **描述**：应用启动后 5 秒异步检查 GitHub Releases 最新版本号，若发现新版本则显示更新提示条（顶部黄色横幅），包含版本号 + 更新日志链接 + 「立即下载」按钮。用户可关闭提示。检查频率：每 24 小时最多一次（持久化 last_check 时间戳）。设置中可关闭自动检查。
- **后端实现**：v1.13.0 已实现 `crates/core/src/update_check.rs`（纯逻辑模块：parse_semver + is_newer_version + should_check + UpdateCheckResult + UpdateCheckConfig）+ `crates/tauri-app/src/commands/settings.rs`（3 IPC 命令：check_for_updates + get_update_check_config + set_update_check_enabled + fetch_github_release 辅助函数 `.no_proxy()` 铁律一合规）
- **S87 前端增强**：新建 `ui/src/update-banner.js`（启动后 5s 异步调用 check_for_updates + 发现新版本时显示顶部黄色横幅 + 版本号 + 更新日志链接 + 下载按钮 + 关闭按钮）
- **验收标准**：
  - AC-1：应用启动后自动检查更新（每 24 小时最多一次）。（TC-UPD-001）
  - AC-2：发现新版本时侧栏或顶栏显示更新提示徽标。（TC-UPD-002）
  - AC-3：点击徽标显示更新详情（版本号、更新日志摘要、下载链接）。（TC-UPD-003）
  - AC-4：更新检查请求仅发往 GitHub API，不含用户数据。（TC-UPD-004）
  - AC-5：设置中可关闭自动更新检查。（TC-UPD-005）
  - AC-6：网络不可用时静默跳过检查，不报错。（TC-UPD-006）
- **契约**：`crates/core/src/update_check.rs`（纯逻辑）+ `crates/tauri-app/src/commands/settings.rs`（3 IPC）+ `ui/src/update-banner.js`（前端横幅）
- **关键文件**：`crates/core/src/update_check.rs`、`crates/tauri-app/src/commands/settings.rs`、`ui/src/update-banner.js`、`ui/src/main.js`
- **注意**：铁律一 — 请求 GitHub API 使用 `.no_proxy()` 直连（已在 v1.13.0 后端实现）

### 3.4 S89: P2-4 macOS 代码签名与公证 ✅

#### REQ-SEC-023 macOS 代码签名与公证
- **优先级**：P2 ｜ **状态**：Implemented ｜ **依赖**：无 ｜ **实现日期**：2026-08-22
- **描述**：配置 Tauri 构建管线实现 macOS 代码签名（Developer ID Application 证书）+ 公证（notarytool）。签名后应用启动不再显示「无法验证开发者身份」警告。配置 `tauri.conf.json` 的 `macOS.signingIdentity` + `entitlements`（网络权限 + 文件访问权限）。CI/CD 中通过环境变量注入证书。
- **验收标准**：
  - AC-1：`tauri build` 生成已签名的 `.app` 包（TC-SEC-SIGN-001）
  - AC-2：`codesign -v` 验证签名有效（TC-SEC-SIGN-002）
  - AC-3：`spctl --assess --type execute` Gatekeeper 通过（TC-SEC-SIGN-003）
  - AC-4：公证完成，`xcrun stapler staple` 验证（TC-SEC-SIGN-004）
  - AC-5：启动时无「无法验证开发者身份」警告（TC-SEC-SIGN-005）
- **契约**：`crates/tauri-app/tauri.conf.json`（`macOS.signingIdentity` + `entitlements` 路径）+ `crates/tauri-app/entitlements.plist`（权限声明）+ `EchoMind/.github/workflows/release.yml`（CI 签名步骤）+ `.github/workflows/ci.yml`（CI 签名步骤）+ `scripts/sign-macos.sh`（本地签名脚本）
- **关键文件**：`crates/tauri-app/tauri.conf.json`、`crates/tauri-app/entitlements.plist`、`scripts/sign-macos.sh`、`EchoMind/.github/workflows/release.yml`、`.github/workflows/ci.yml`
- **注意**：需要 Apple Developer 账号（用户提供证书 + API Key）。若无证书则跳过签名+公证步骤，不影响 Free 版本构建。`signingIdentity: "-"` 作为默认值（ad-hoc 签名），`APPLE_SIGNING_IDENTITY` 环境变量覆盖为 Developer ID。
- **CI Secrets**：`SIGNING_CERTIFICATE_P12`（base64 编码的 .p12 证书）+ `SIGNING_PASSWORD`（.p12 密码）+ `APPLE_ID` + `APPLE_PASSWORD`（App-Specific Password）+ `APPLE_TEAM_ID`

### 3.5 S90: 全局搜索增强

#### REQ-IX-007 全局搜索增强
- **优先级**：P2 ｜ **状态**：Draft ｜ **依赖**：REQ-RAG-040
- **描述**：当前有对话全文搜索（FTS5）和文档列表搜索（文件名过滤）。增强为统一全局搜索面板（⌘⇧F），同时搜索：对话消息（FTS5）+ 文档标题/摘要（FTS5）+ 知识图谱实体（entity name like）。搜索结果分组展示（对话 / 文档 / 实体），每组 top-5。点击结果直接跳转到对应位置。
- **验收标准**：
  - AC-1：⌘⇧F 打开全局搜索面板（TC-GSEARCH-001）
  - AC-2：搜索结果分组：对话消息（top-5）+ 文档（top-5）+ 知识图谱实体（top-5）（TC-GSEARCH-002）

  - AC-4：点击文档结果跳转到文档详情面板（TC-GSEARCH-004）
  - AC-5：点击实体结果跳转到知识图谱查看器并高亮实体（TC-GSEARCH-005）
  - AC-6：搜索框支持中英文混合查询（TC-GSEARCH-006）
- **契约**：`ui/src/global-search.js`（增强现有模块：搜索框 + 分组结果渲染 + 跳转逻辑）+ `crates/tauri-app/src/commands/conversation.rs`（`global_search` IPC 统一查询）+ `crates/infra/src/sqlite_storage.rs`（`global_search` 方法：FTS5 messages + FTS5 documents + entities LIKE）
- **关键文件**：`ui/src/global-search.js`、`crates/tauri-app/src/commands/conversation.rs`、`crates/infra/src/sqlite_storage.rs`
