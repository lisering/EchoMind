- **架构收益 (20%)**：对代码架构的改善、可复用性、技术债减少
- **风险控制 (10%)**：引入 bug 的风险、数据安全、向后兼容性

## 2. 选定功能

### 2.1 S1: 文档原文导出（REQ-EXP-004）

**目标**：用户可从知识库导出文档的原始文件副本。文档列表项右键菜单提供「导出原文」选项，通过 Tauri 保存对话框选择保存位置。导出的文件与导入时完全一致。

**后端**：
- 新增 `export_document_original` IPC 命令：接收 `doc_id` + `dest_path`，将数据目录中的文档副本复制到目标路径
- 复用 `Storage::list_documents()` 查找文档 `file_path`
- 使用 `tokio::fs::copy()` 复制文件（内核级零拷贝）

**前端**：
- `ui/src/context-menu.js`：文档右键菜单新增「导出原文」选项
- 调用 Tauri `save` 对话框获取保存路径 → IPC 复制文件
- `ui/src/ipc.js`：新增 `exportDocumentOriginal` API

**改动文件**：

|---|---|
| `crates/tauri-app/src/commands/document.rs` | 新增 `export_document_original` IPC |
| `crates/tauri-app/src/lib.rs` | 注册新命令 |
| `ui/src/ipc.js` | 新增 `exportDocumentOriginal` |
| `ui/src/context-menu.js` | 右键菜单新增导出原文 |
| `ui/locales/{en,zh-CN}.json` | i18n 键 |

### 2.2 S2: 索引重建前端 UI + 取消支持（REQ-VEC-009）

**目标**：用户可对已索引文档发起「重建索引」操作。点击后弹出确认对话框，确认后文档状态变为 Processing，旧 chunks 与向量被清理，重新执行索引。重建过程中可取消。

**后端**：
- 新增 `rebuild_index` IPC 命令：封装 `retry_index` 逻辑，适用于 Indexed 状态文档
- 复用现有 `retry_index_inner` 逻辑（清理旧 chunks → 重新索引 + 嵌入）
- 复用 `import_cancel_flag` 实现取消（AC-4）

**前端**：
- `ui/src/context-menu.js`：Indexed 文档右键菜单新增「重建索引」选项
- 调用 `showConfirmDialog()` 确认（AC-1）
- `ui/src/ipc.js`：新增 `rebuildIndex` API

### 2.3 S3: 数字与文件大小本地化（REQ-I18N-003）

**目标**：文件大小显示使用人类可读格式（B/KB/MB/GB），采用 1024 进制，保留 1 位小数。大数字使用千分位分隔符。百分比显示保留整数。统一三处重复的 `formatBytes` 实现。

**纯前端实现**：
- `ui/src/utils.js`：增强 `formatBytes` 支持 GB/TB + 新增 `formatNumber`（千分位）+ `formatPercent`
- `ui/src/kb-stats.js`：移除重复 `formatBytes`，改为 import from utils.js
- `ui/src/settings-local-llm.js`：移除重复 `formatModelSize`，改为 import from utils.js

**改动文件**：

### 2.4 S4: 回到顶部与滚动定位（REQ-NAV-005）

**目标**：对话区滚动超过一屏后，右下角显示「回到顶部」浮动按钮。点击后平滑滚动到对话区顶部。流式生成中自动滚动到底部，用户手动向上滚动后暂停自动滚动，显示「新消息」提示按钮。

**纯前端实现**：
- `ui/src/scroll-manager.js`：新建滚动管理模块
  - 监听 `#chatMessages` scroll 事件
  - 滚动 > 1 视口高度 → 显示「回到顶部」按钮
  - 点击 → `scrollTo({ top: 0, behavior: 'smooth' })`
  - 流式生成中：检测用户向上滚动 → 暂停 auto-scroll → 显示「新消息」按钮
  - 点击「新消息」→ 恢复 auto-scroll + 滚动到底部
- `ui/index.html`：浮动按钮容器
- `ui/styles/components.css`：按钮样式

**改动文件**：
