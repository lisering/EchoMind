## 5. 技术调研要点

### S54: 知识图谱导出
- **GraphML**: XML 格式，Gephi/Cytoscape 标准。手动生成 XML 字符串（无需 quick-xml）
- **JSON-LD**: W3C 标准，Neo4j/语义 Web。使用 serde_json（已有依赖）
- 数据来源: `entity_relations` + `entities` 表，`list_all_relations()` 已存在
- 引用: http://graphml.graphdrawing.org/ / https://www.w3.org/TR/json-ld/

### S55: 文档摘要自动生成
- `Document` 结构体新增 `summary: Option<String>` 字段
- 导入管线嵌入完成后异步 spawn LLM 摘要任务（不阻塞导入）
- 文档文本截断前 4000 字符作为 LLM 输入
- 失败优雅降级（summary 保持 None）
- 引用: AnythingLLM document summarization

### S56: 对话模板/快捷指令系统
- 复用 settings 表 JSON 存储（与 workflow 模板模式一致）
- `slash-commands.js` 合并系统指令（6 个硬编码）+ 自定义模板
- `PromptTemplate` 结构体: id/name/label/desc/icon/prompt_template/created_at
- 引用: ChatGPT Custom Instructions / Obsidian Templates

### S57: Markdown 双向链接
- `regex` crate 匹配 `\[\[([^\]]+)\]\]`（已是依赖）
- 新增 `wiki_links` 表: source_doc_id / target_doc_name / target_doc_id / chunk_id
- 导入时解析 `[[link]]` 并建立索引
- 前端 `[[link]]` 渲染为可点击链接 + 反向链接面板
- 引用: Obsidian Wiki Links / Backlinks

### S58: 对话分支/版本树
- 复用 `turn_active_versions` 表 + `ChatMessage.turn_group/version` 字段
- `ConversationTreeNode` 树结构: turn_group / versions / active_version / children
- D3.js v7 tree layout（已有 `ui/vendor/d3.min.js`）
- 引用: ChatGPT Branching / D3 hierarchy
