## 4. 关键技术决策

### S44: .docx 导入
- **crate 选型**: `docx-rs` v0.4.22（纯 Rust，MIT），排除 mammoth（HTML 中间格式增加开销）
- **实现模式**: DocxLoader 实现 Loader trait，复用 DocxLoader/HtmlLoader 模式
- **ALLOWED_EXTENSIONS**: 8→9（新增 "docx"）

### S45: .html 导入
- **crate 选型**: `html2text` v0.17.1（纯 Rust，MIT）
- **实现模式**: HtmlLoader 实现 Loader trait，保留标题层级+列表结构
- **ALLOWED_EXTENSIONS**: 9→10（新增 "html"+"htm"）

### S46: 浅色主题
- **方案**: CSS 变量覆盖（`[data-theme="light"]` ~40 变量），零组件代码改动
- **关键设计**: `--accent-text` 变量解决 Tailwind CDN JIT 硬编码问题
- **三模式**: dark / light / system（@media prefers-color-scheme）
- **新增 IPC**: set_theme / get_theme（settings 表键 `ui.theme`）

### S47: 语音输入 + TTS
- **方案**: Web Speech API（浏览器原生，零依赖）
- **SpeechRecognition**: 麦克风转写，不支持时优雅降级隐藏入口
- **speechSynthesis**: TTS 朗读，语速可调（0.5~2.0）
- **新增模块**: `ui/src/voice-input.js`
- **设置键**: `voice.rate`

### S48: 网页搜索集成
- **方案**: DuckDuckGo Instant Answer API + RRF 融合
- **架构**: `WebSearchProvider` trait（core）+ `DuckDuckgoProvider`（infra）+ `web_search` 融合引擎（core）
- **集成**: ChatEngine `with_web_search()` builder，检索后阈值判断→搜索→融合
- **opt-in**: 默认关闭（`rag.web_search_enabled`）
- **新增 IPC**: set_web_search_enabled / web_search（138 总命令）

## 8. 经验总结

- **v1.1 规划模式有效**: ROI 评估 → 技术调研 → 原子计划 → SRS 扩展 → README 更新的流程在 v1.1 中验证成功，v1.2 沿用
- **纯 Rust crate 优先**: docx-rs / html2text 均为纯 Rust，无系统依赖，编译/测试零摩擦
- **零依赖方案优先**: 浅色主题（CSS 变量）和语音输入（Web Speech API）零新增依赖，是最简洁的方案
- **opt-in 默认关闭**: 网页搜索等涉及网络的功能默认关闭，符合「本地优先」承诺
