## 技术决策

1. **独立模块**：语音输入逻辑放在 `ui/src/voice-input.js` 独立模块，而非塞入 `chat.js`，保持单一职责。
2. **优雅降级**：检测 `window.SpeechRecognition` / `window.webkitSpeechRecognition` / `window.speechSynthesis`，不支持时隐藏对应 UI 入口。
3. **localStorage 持久化**：TTS 语速存储在 localStorage（key: `voice.rate`），不走后端 IPC（纯前端偏好）。
4. **语言跟随 UI**：SpeechRecognition 和 TTS 的语言跟随当前 UI locale（zh-CN / en-US），无需额外配置。
5. **E2E Mock 策略**：tauri-stub.js 中始终覆盖 Web Speech API（Chromium 原生在 headless 下不触发 onend），mock 结构匹配真实 API 的 array-like results。
