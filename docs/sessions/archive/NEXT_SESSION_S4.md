## 本 Session 目标

**S4：用户场景验收评估。** 从真实用户场景出发，验证 S3 提出的重整方案可行性。只审计，不写新功能代码。

## 评估方法

### 1. 用户画像定义

定义 3 类典型用户画像，为每类画像设计核心场景：

| 画像 | 特征 | 核心需求 |
|---|---|---|
| **小明（新手用户）** | 首次使用 RAG 工具，不了解技术概念 | 导入文档 → 提问 → 获得答案，零配置 |
| **小王（知识工作者）** | 研究员/学生，定期导入大量文档 | 批量管理、精确搜索、导出引用 |
| **小李（高级用户）** | 开发者/技术爱好者，需要精细控制 | 自定义模型、调参、API 集成 |

### 2. 场景覆盖率评估

为每类用户画像评估以下场景的完整性和流畅度：

**新手用户场景**：
- S-A：首次打开 → 开始对话（≤ 3 步）
- S-B：导入第一个文档 → 提问关于文档内容
- S-C：切换对话 → 继续提问
- S-D：导出对话为 Markdown
- S-E：发现并使用混合搜索

**知识工作者场景**：
- S-F：批量导入 50+ 文档 → 管理知识库
- S-G：按标签/格式筛选文档
- S-H：全文搜索历史对话
- S-I：导出文档为 PDF/HTML
- S-J：使用快捷指令模板

**高级用户场景**：
- S-K：配置本地 LLM（GGUF 模型下载）
- S-L：切换嵌入模型
- S-M：调整 RAG 参数（top_k/threshold/expansion）
- S-N：使用 Agent 模式进行多步推理
- S-O：文件监听自动同步

### 3. 智能模式方案验证

验证 S3 提出的「智能模式」方案能否覆盖 80%+ 场景：

| 智能模式 ON | 覆盖场景 | 用户感知 |
|---|---|---|
| 混合搜索 ✅ | S-B, S-F, S-H | 搜索结果更准 |
| Rerank ✅ | S-B, S-F | 最相关内容排前面 |
| 压缩 2x ✅ | S-N | 节省 Token，回答更长 |
| 语义缓存 ✅ | S-C | 重复问题秒答 |
| Contextual ✅ | S-B, S-F | 文档标注提升精度 |

### 4. 设置面板 8 分区方案验证

验证 S3 提出的 8 分区重整方案：

| # | 新分区 | 包含内容 | 用户场景覆盖 |
|---|---|---|---|
| 1 | 模型配置 | LLM 配置 + 模式 + 嵌入模型 | S-A, S-K, S-L |
| 2 | 外观与语言 | 主题 + 语言 + 语音 + PDF | — |
| 3 | 知识库管理 | 文件同步 + 分块 + RAG 参数 | S-F, S-M |
| 4 | 安全与隐私 | 安全 + 备份 | — |
| 5 | 智能检索 | VLM + Rerank + HyDE + Agent + 记忆 | S-N |
| 6 | 高级调优 | Token + 采样 + 硬件 + KV Cache | S-K, S-M |
| 7 | 应用设置 | 窗口 + 自启 + 日志 + 更新 | — |
| 8 | 快捷指令 | 模板管理 | S-J |

### 5. 输入区 2 toggle 方案验证

验证保留「混合搜索 + 网页搜索」是否覆盖核心场景：

| 场景 | 需要的 toggle | 覆盖 |
|---|---|---|
| 普通问答 | 无需 toggle | ✅ |
| 搜索知识库 | 混合搜索 | ✅ |
| 联网查询最新信息 | 网页搜索 | ✅ |
| 多步推理任务 | Agent 模式（设置中启用） | ✅ |
| 持久化记忆 | 记忆（设置中启用） | ✅ |
