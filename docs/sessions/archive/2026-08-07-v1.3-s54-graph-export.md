## 3. 关键设计

### 3.1 graph_export.rs — 纯函数模块

- **`export_graphml(entities, relations) -> String`**: 手动拼接 GraphML XML 字符串
  - XML 声明 `<?xml version="1.0" encoding="UTF-8"?>`
  - `<graphml>` 根元素（带命名空间）
  - `<graph id="G" edgedefault="directed">` 有向图
  - 遍历 entities → `<node id="text"><data key="entity_type">type</data></node>`
  - 遍历 relations → `<edge source="subject" target="object"><data key="relation_type">type</data><data key="confidence">0.9</data></edge>`
  - XML 特殊字符转义：`&`→`&amp;` `<`→`&lt;` `>`→`&gt;` `"`→`&quot;`

- **`export_jsonld(entities, relations) -> String`**: 使用 serde_json 构建 JSON-LD
  - `@context` 定义实体/关系类型映射
  - `@graph` 数组：节点 `{"@id": text, "@type": "Entity", "entityType": type}` + 边 `{"@id": id, "@type": "Relation", "subject": ..., "relationType": ..., "object": ..., "confidence": ...}`
  - `serde_json::to_string_pretty()` 序列化

### 3.2 export_graph IPC 命令

- 签名: `export_graph(format: String, state: State<'_, AppState>) -> Result<String, String>`
- format 参数: `"graphml"` 或 `"jsonld"`
- 逻辑:
  1. `list_all_relations(usize::MAX, 0)` 获取全量关系
  2. 从关系中提取去重实体文本（subject + object）
  3. `get_entity_types(&entity_texts)` 查询实体类型
  4. 构建 `Vec<Entity>`
  5. 调用 `export_graphml()` 或 `export_jsonld()`

> **注意**: Storage trait 没有 `list_all_entities()` 方法。实体从关系中派生（subject + object 去重），再通过 `get_entity_types()` 查询类型。这与 `get_graph_stats_inner` 的实现模式一致。

### 3.3 前端导出按钮

- GraphML 和 JSON-LD 导出按钮添加在现有 SVG/PNG 导出按钮之后（工具栏分隔线后）
- `exportGraphData(format)` 函数：`invoke('export_graph', { format })` → `Blob` → `downloadBlob()`
- 文件名: `knowledge-graph.graphml` / `knowledge-graph.jsonld`
- MIME type: `application/xml;charset=utf-8` / `application/ld+json;charset=utf-8`
