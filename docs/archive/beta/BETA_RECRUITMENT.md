### ❓ 常见问题

**Q: 需要编程基础吗？**  
A: 不需要。EchoMind 面向所有知识工作者，界面友好，开箱即用。

**Q: 需要购买 API Key 吗？**  
A: 建议自备 OpenAI/Azure/兼容端点的 API Key 以体验完整功能。也可先用演示模式免费体验核心流程。

**Q: 数据安全吗？**  
A: 绝对安全。文档、向量、对话历史全部本地加密存储（SQLCipher AES-256），API Key 本地加密存储，无任何数据上传。

**Q: 如果遇到 Bug 怎么办？**  
A: 专属反馈通道 24 小时响应，严重 Bug 24 小时内修复发布热修复版。

**Q: 测试结束后数据怎么办？**  
A: 您的所有数据完全保留，正式版发布后无缝升级，数据无缝迁移。

## 4. 深度访谈提纲（45 分钟）

### 开场 (5 分钟)
- 自我介绍、项目背景说明
- 确认录音授权、保密承诺
- 破冰：最近在忙什么项目？

### 核心体验回顾 (15 分钟)
1. **典型工作日场景**：请描述一个典型的使用 EchoMind 的工作日
2. **核心工作流**：从导入文档 → 提问 → 获得答案 → 引用来源 → 后续动作，完整走一遍
3. **替代方案对比**：之前怎么解决这个问题？EchoMind 替代了什么工具？好在哪？差在哪？

### 深度体验探究 (20 分钟)
| 维度 | 探究问题 |
|------|----------|
| **文档导入** | 格式支持够不够？导入速度、进度反馈、错误处理如何？ |
| **检索质量** | 向量/关键词/混合检索，哪种最常用？召回率、精准度如何？ |
| **回答质量** | 幻觉情况？引用准确吗？上下文理解够不够？ |
| **降级体验** | 向量检索失败/网络断开时，降级提示清不清晰？体验是否连贯？ |
| **演示模式** | 无 Key 用户的首次体验如何？模板回答覆盖面够不够？ |
| **设置/配置** | LLM 配置、检索参数、预算设置，哪里不直观？ |
| **导出/分享** | Markdown 导出格式够不够？还需要什么格式？ |

### 痛点与期望 (10 分钟)
1. **最想吐槽的 3 个问题**：________________________
2. **如果只有 1 个魔法愿望，最想改什么**：___________
3. **如果推荐给同事，你会怎么说？** ________________

### 结语 (5 分钟)
- 总结核心诉求
- 确认后续跟进方式
- 赠送感谢礼品信息确认
