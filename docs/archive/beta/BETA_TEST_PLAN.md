# EchoMind Beta 测试计划

**版本**: v3.1.1-beta

## 1. 测试背景与目标

### 1.1 产品概述
EchoMind 是一款本地优先的智能知识库助手，核心价值：
- **隐私优先**: 文档解析、分块、向量化全在本地完成
- **BYOK 模式**: 用户自带 API Key，使用自己的 LLM 端点
- **混合检索**: 向量 + 关键词双路检索，支持重排序、HyDE、图扩展
- **演示模式**: 无需 API Key 即可体验基础 RAG 功能

### 1.2 测试目标
| 目标 | 优先级 | 成功指标 |
|------|--------|----------|
| 核心功能可用性 | P0 | 核心流程完成率 ≥ 95% |
| 用户体验满意度 | P0 | NPS ≥ 30，任务完成时间符合预期 |
| 性能基线建立 | P1 | 首次聊天 < 3s，检索 < 500ms，导入 100MB < 30s |
| 稳定性验证 | P0 | 连续 1 小时对话无崩溃，内存增长 < 100MB |
| 隐私合规验证 | P0 | 无数据上传、API Key 本地加密存储 |

## 5. 反馈收集与分析框架

### 5.1 定量指标

| 指标 | 采集方式 | 目标值 |
|------|----------|--------|
| 任务完成率 | 自动埋点 | ≥ 95% |
| 平均任务完成时间 | 自动埋点 | 核心任务 < 2min |
| 错误率 | 自动埋点 | < 2% |
| NPS | 问卷 | ≥ 30 |
| 功能使用频次分布 | 自动埋点 | 核心功能覆盖 ≥ 80% 用户 |
| 留存率 (7天) | 自动埋点 | ≥ 40% |

### 5.2 定性反馈

| 方式 | 频次 | 样本量 | 关注点 |
|------|------|--------|--------|
| 结构化问卷 | 每周 | 全量 | 易用性、稳定性、功能缺失 |
| 深度访谈 | 双周 | 5-10人/次 | 深度体验、工作流契合度 |
| 社区反馈 | 持续 | 全量 | Bug 报告、功能建议 |
| 可用性测试 | 双周 | 3-5人/次 | 任务完成路径、困惑点 |

### 5.3 自动化埋点设计

```json
{
  "event": "chat_completed",
  "properties": {
    "conversation_id": "uuid",
    "duration_ms": 12500,
    "token_usage": {"prompt": 1200, "completion": 800},
    "retrieval_mode": "hybrid",
    "rerank_enabled": true,
    "sources_count": 5,
    "degraded": false,
    "error": null
  }
}
```

**核心事件**：app_start, config_completed, document_imported, chat_started, chat_completed, chat_error, export_completed, settings_changed, budget_exceeded, crash

## 7. 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| 招募用户不足 | 中 | 高 | 多渠道并行、激励机制（延长免费期、赠送额度） |
| 关键 Bug 无法及时修复 | 中 | 高 | 设立 P0 专人跟进、每日站会跟进 |
| 性能不达标 | 低 | 高 | 预留性能优化 sprint、必要时延期 |
| 用户反馈噪音大 | 中 | 中 | 结构化问卷 + 自动化分类、标签化管理 |
| 数据泄露风险 | 极低 | 极高 | 代码审计、渗透测试、隐私合规审查 |
