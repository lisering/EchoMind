## 三、发现的缺陷与问题清单

### P1 严重问题

#### BUG-FIND-001：直接调用 `invoke('import_files')` 不触发付费墙 UI
- **现象**：测试中通过 `window.__TAURI__.core.invoke('import_files', { paths: ['/mock/test.pdf'] })` 直接调用 IPC 时，PRO_REQUIRED 错误被抛出但未触发付费墙 Modal。
- **根因**：付费墙触发逻辑位于 `importPaths()` 函数中（line 1640），而非 IPC 调用本身。直接调用 `invoke('import_files')` 绕过了 `importPaths()` 的错误处理逻辑。
- **影响**：如果有其他代码路径直接调用 `import_files` 而不经过 `importPaths()`，付费墙不会弹出。
- **修复建议**：将 `LIMIT_REACHED` / `PRO_REQUIRED` 错误识别逻辑提取为独立函数，或在 IPC 调用层统一拦截。

#### BUG-FIND-002：删除按钮选择器在 hover 前不可见导致超时
- **现象**：测试 `3.13 删除文档后列表更新` 超时失败（30s）。
- **根因**：删除按钮使用 `invisible group-hover:visible` CSS 类，在 Playwright 中 `click()` 需要先 hover 才能使按钮可见。但测试尝试直接 `page.locator('button[title="删除文档"]').click()` 会导致 strict mode violation 或超时。
- **影响**：自动化测试中需要额外 hover 步骤，增加了测试复杂度。
- **修复建议**：测试中先 hover 文档项再操作按钮，或使用 `page.evaluate` 直接调用 DOM click。

#### BUG-FIND-003：侧栏折叠宽度过渡时间导致瞬时断言失败
- **现象**：测试 `9.2 折叠后侧栏宽度 56px` 失败。
- **根因**：侧栏有 `transition-all duration-200` (200ms 过渡)，点击折叠按钮后立即检查宽度时，CSS 过渡尚未完成，实际宽度介于 240px 和 56px 之间。
- **影响**：用户可感知的视觉延迟，但功能正常。
- **修复建议**：测试中添加 `waitForTimeout(300)` 等待过渡完成。

### P2 一般问题

#### BUG-FIND-004：`.md` line-height 计算值与预期不符
- **现象**：CSS 声明 `line-height: 1.8`，但计算值并非简单的 `14 * 1.8 = 25.2px`，受继承和盒模型影响。
- **根因**：浏览器计算 line-height 时可能受到父元素影响。
- **影响**：无实际视觉问题，仅测试断言需调整。

#### BUG-FIND-005：Toast 容器 `space-y-2` 在 flex 布局下 gap 计算差异
- **现象**：测试断言 `gap` 为 `8px`，但 `space-y-2` 在某些情况下使用 `margin` 而非 `gap`。
- **根因**：Tailwind `space-y-*` 工具类通过 `margin-top` 实现间距，而非 `gap` 属性。
- **影响**：视觉间距正确，但测试断言方式需修正。

#### BUG-FIND-006：输入栏聚焦边框色未即时变化
- **现象**：测试 `13.5 输入栏聚焦时边框色变化` 失败。聚焦后边框色仍为 `rgba(42, 43, 47, 0.996)`（line 色），而非 accent 色。
- **根因**：`focus-within:border-accent/60` 使用 60% 透明度的 accent 色，在 Tailwind 的 JIT 编译下可能渲染为 `rgba(56, 189, 248, 0.6)`。但 `getComputedStyle` 返回的 `borderColor` 可能由于浏览器合成行为返回了原始 line 色值。
- **影响**：视觉上可能有轻微差异，但功能正常。
- **修复建议**：测试中检查 border 是否包含 accent 的 RGB 值，或使用截图对比。

#### BUG-FIND-007：思考指示器文案被 chat_phase 事件快速覆盖
- **现象**：测试 `4.3 思考指示器默认文案"正在检索知识库…"` 失败。
- **根因**：`send()` 函数设置初始文案为"正在检索知识库…"，但 mock 几乎立即触发 `chat_phase` 事件，将文案更新为"preparing"阶段的文案。测试在读取文案时，事件已经更新了它。
- **影响**：用户可能看到"正在检索知识库…"的时间极短（<100ms），实际上看到的是 chat_phase 事件的文案。
- **修复建议**：测试中使用更快的断言或 mock 延迟 chat_phase 事件。

#### BUG-FIND-008：现有 E2E-RAG-004 引用块分数断言失败
- **现象**：现有测试 `E2E-RAG-004 引用块含文档名、片段预览、分数` 失败。
- **根因**：Mock 的 `chat_sources` 事件载荷中 `score` 字段格式与测试期望不匹配。测试期望包含百分比分数（如 `85%`），但 mock 可能返回的是小数形式。
- **影响**：仅影响自动化测试，不影响实际功能。
- **修复建议**：修正 mock 数据或调整测试断言。

### P3 优化建议

#### OPT-001：缺少确认对话框
- **现象**：删除文档操作直接执行，没有确认对话框。
- **影响**：用户可能误删文档。
- **建议**：SRS REQ-IX-005 已规划确认对话框，建议尽快实现。

#### OPT-002：缺少右键菜单
- **现象**：文档列表项和会话列表项没有右键菜单。
- **影响**：用户无法快速访问常用操作（复制文件名、重建索引等）。
- **建议**：SRS REQ-IX-001 已规划右键菜单，建议尽快实现。

#### OPT-003：缺少全局搜索
- **现象**：没有文档搜索或会话搜索功能。
- **影响**：文档数量多时难以查找。
- **建议**：SRS REQ-ING-007 已规划文档搜索，建议实现。

#### OPT-004：缺少骨架屏
- **现象**：文档列表和会话列表加载时无骨架屏。
- **影响**：加载时间较长时用户看到空白区域。
- **建议**：SRS REQ-IX-007 已规划骨架屏，建议实现。

#### OPT-005：缺少暗/亮主题切换
- **现象**：当前只有暗色主题，没有切换为亮色主题的选项。
- **影响**：在明亮环境下使用可能不适。
- **建议**：后续版本考虑增加亮色主题。

#### OPT-006：配置向导缺少返回/上一步按钮
- **现象**：向导只有"验证并开始"按钮，没有返回或跳过按钮。
- **影响**：用户如果不想配置，无法跳过。
- **建议**：添加"稍后配置"选项。

#### OPT-007：缺少拖拽排序
- **现象**：文档列表和会话列表不支持拖拽排序。
- **影响**：用户无法自定义排序顺序。
- **建议**：SRS REQ-IX-002 已规划拖拽排序。

#### OPT-008：模型下载进度使用 toast 而非进度条
- **现象**：ONNX 模型下载进度通过 toast 推送百分比，而不是使用进度条。
- **影响**：多个进度 toast 会堆叠，体验不佳。
- **建议**：使用专用进度条组件显示下载进度。
